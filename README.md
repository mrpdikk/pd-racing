# Perfect Kart 

A hoverbike racing mod of Perfect Dark (N64). Race and fight to finish first.

Runs on N64 (tested with EverDrive x7).

## What you need

- US V1.1 rom i.e. ntsc-final, as big-endian .z64 file, MD5 `e03b088b6ac9e0080440efed07c1e40f`.
- patch file from the [latest release](https://github.com/mrpdikk/pd-racing/releases).
- N64 Expansion Pak
